아래는 결정 근거로 남겨둡니다.


### ① 어떤 도메인을 쓸 것인가

- **`fairtoon.com` 권장.** 가장 보편적이고, 해외 이용자에게도 자연스럽습니다. 캠페인 사이트라 신뢰도 면에서도 `.com`이 유리합니다
- `.kr` / `.co.kr`은 한국 대상임을 분명히 하지만 해외 확장 시 어색합니다
- 여력이 되면 `.com` + `.kr` 동시 취득 후 `.kr`은 `.com`으로 넘겨주는 방식도 가능합니다. 상표 보호 성격입니다


### ② 어디서 등록할 것인가

| 등록기관 | 대략 연 비용(.com) | 특징 |
|----------|--------------------|------|
| Cloudflare Registrar | 가장 저렴 (원가 수준) | 마진을 붙이지 않음. DNS 관리가 빠르고 무료. 화면이 영어 |
| Porkbun / Namecheap | 저렴~보통 | 첫해 할인이 크고 갱신가가 오름. 영어 |
| 가비아 / 후이즈 | 보통~다소 높음 | 한국어 지원, 국내 결제·세금계산서 편리. `.kr` 동시 등록 가능 |

- 비용만 보면 Cloudflare, 관리 편의(한국어·국내 결제)를 보면 가비아입니다
- **정확한 가격은 등록 직전 해당 사이트에서 확인해야 합니다.** 환율과 프로모션에 따라 달라집니다
- 첫해 할인가보다 **갱신가**를 보고 고르십시오. 도메인은 매년 내는 비용입니다


### ③ 누구 명의로 등록할 것인가

- 대표님 개인 / 지호님 / 법인 중 선택
- **소유 계정이 DNS를 설정합니다.** 리포는 지호님 계정이지만 도메인 소유자가 달라도 무방합니다. 다만 DNS 값을 넣는 작업은 소유 계정에 로그인해야 하므로, 그 작업을 누가 할지 함께 정해야 합니다
- 갱신 실패로 도메인이 만료되면 사이트가 통째로 죽습니다. **자동 갱신을 켜고, 결제 수단이 유효한 계정**으로 두십시오


## 3. 단계별 할 일


### 1단계 — 도메인 등록 [대표님]

1. 등록기관에서 `fairtoon.com` 검색 → 장바구니 → 결제
2. **자동 갱신 켜기**
3. **WHOIS 개인정보 보호 켜기** (대부분 무료). 켜지 않으면 등록자 이름·주소·연락처가 공개 조회됩니다
4. 등록 완료 후 PM에게 알려주십시오

검증: 등록기관 관리 화면에 도메인이 보이고, `whois fairtoon.com`에 등록 정보가 나오면 완료.


### 2단계 — DNS 레코드 설정 [도메인 소유 계정 보유자]

등록기관의 DNS 관리 화면에서 아래를 입력합니다.

**apex 도메인 (fairtoon.com) — A 레코드 4개**

```
A   @   185.199.108.153
A   @   185.199.109.153
A   @   185.199.110.153
A   @   185.199.111.153
```

**IPv6도 함께 (권장, AAAA 레코드 4개)**

```
AAAA   @   2606:50c0:8000::153
AAAA   @   2606:50c0:8001::153
AAAA   @   2606:50c0:8002::153
AAAA   @   2606:50c0:8003::153
```

**www 서브도메인 — CNAME 1개**

```
CNAME   www   3samchoi-svg.github.io.
```

- `@`는 도메인 그 자체를 뜻합니다. 등록기관에 따라 빈칸이거나 도메인 전체를 적습니다
- CNAME 값 끝의 마침표는 등록기관에 따라 필요하거나 자동으로 붙습니다
- 이미 들어 있는 기본 주차 레코드(등록기관 광고 페이지)는 지워야 합니다

검증: `dig fairtoon.com +short`에 위 IP 4개가 나오면 완료. 반영까지 보통 수십 분, 최대 48시간.


### 3단계 — 리포에 CNAME 파일 추가 [PM]

리포 루트에 `CNAME` 파일을 만들고 내용은 도메인 한 줄만 넣습니다.

```
fairtoon.com
```

- 확장자 없는 대문자 `CNAME`입니다
- 이 파일이 없으면 Pages 설정에서 넣은 도메인이 배포 때마다 초기화될 수 있습니다
- **push 시점 주의**: 이 파일을 push하는 순간 기존 `3samchoi-svg.github.io/fairtoon/` 접속이 `fairtoon.com`으로 리다이렉트됩니다. DNS가 아직 안 붙어 있으면 현재 살아 있는 사이트가 먹통이 됩니다. **2단계(DNS) 반영을 `dig`로 확인한 뒤에 push**합니다
- 파일은 2026-08-10 로컬에 생성 완료. 커밋·push는 DNS 확인 후 진행

검증: push 후 리포 루트에 파일이 보이면 완료.


### 4단계 — GitHub Pages 설정 [지호님]

리포 → Settings → Pages

1. Custom domain에 `fairtoon.com` 입력 → Save
2. DNS check가 통과할 때까지 대기 (실패하면 2단계 값을 다시 확인)
3. **Enforce HTTPS 체크** — 인증서 발급 전에는 체크박스가 비활성입니다. 발급까지 보통 수십 분, 최대 24시간

검증: `https://fairtoon.com` 접속 시 자물쇠가 뜨고 사이트가 정상 표시되면 완료.


### 5단계 — 사이트 내부 주소 교체 [PM]

지금 `3samchoi-svg.github.io/fairtoon/` 기준으로 박혀 있는 주소를 새 도메인으로 바꿉니다.

- `index.html`의 `canonical` · `og:url` · `twitter:url` · `og:image` · `twitter:image`

이 작업을 하지 않으면 검색엔진이 옛 주소를 정본으로 계속 인식하고, 카카오톡·슬랙 공유 미리보기의 이미지가 깨질 수 있습니다.

검증: 페이지 소스에서 옛 주소가 하나도 검색되지 않으면 완료.

## 4. 주의사항

- **HTTPS 인증서 발급 전까지 경고 화면이 뜰 수 있습니다.** 최대 24시간이며 정상 과정입니다. 이 시간대에 외부에 링크를 뿌리지 마십시오
- **DNS 전파에 시차가 있습니다.** 내 컴퓨터에서는 열리는데 다른 사람은 안 열릴 수 있습니다. 최대 48시간 기다린 뒤 판단하십시오
- **옛 주소는 사라지지 않습니다.** GitHub이 새 도메인으로 자동 연결해 줍니다. 이미 공유한 링크는 계속 살아 있습니다
- **도메인 만료 = 사이트 사망.** 자동 갱신과 결제 수단을 반드시 확인하십시오
- **네임서버를 통째로 바꾸는 방식(예: Cloudflare로 이전)을 택하면** 위 DNS 설정을 그쪽 화면에서 해야 합니다. 이 경우 Cloudflare의 프록시(주황 구름)는 GitHub Pages와 함께 쓸 때 설정이 까다로우니, 처음에는 프록시를 끈 상태(회색 구름)로 두는 편이 안전합니다
