# 작품 카탈로그 확대 계획 (1단계 · 연재작)


작성: 2026-08-11 · 클상무(PM) · 승인: 대표님 (2026-08-11 "1번 진행하자")
대상: 현재 50편 → 연재 중 작품 약 1,100편 추가


## 1. 왜 하는가


사이트가 내건 약속은 "이 작품, 어디서 정식으로 볼 수 있나"에 답하는 것이다. 그런데 지금 확답할 수 있는 것은 DB에 있는 50편뿐이고, 나머지는 플랫폼 검색창으로 넘기는 게 전부다. 카탈로그를 늘리면 그 약속이 지켜지는 횟수가 늘어난다. **표지보다 사이트 본질에 가까운 작업이다.**

작업이 빠른 이유는 3사 API 파이프라인이 이미 서 있기 때문이다. 편수가 늘어도 사람 손은 늘지 않는다.


## 2. 수집 대상과 경로


| 플랫폼 | 대상 | 경로 | 예상 |
|--------|------|------|------|
| 네이버웹툰 | 요일 연재 전체 | `api/webtoon/titlelist/weekday` → `api/article/list/info` | 777편 |
| 카카오웹툰 | 요일 연재 전체 | `section/v1/pages/general-weekdays` → 작품 페이지 og:image | 202편 |
| 카카오페이지 | 요일 연재 (웹툰만) | `view/v1/list/dayofweek` | 약 126편 |

네이버는 작품별 정보 API 한 번으로 장르·줄거리·공유 이미지·연령등급이 모두 나온다. 카카오페이지도 목록 API 한 번에 다 나온다. 카카오웹툰만 표지 때문에 작품 페이지를 한 번 더 읽는다.


## 3. 필터 — 타협하지 않을 것


1. **성인물 전면 제외.** 청소년 대상 캠페인이다. 네이버 `adult` 플래그와 `age.type=RATE_19`, 카카오 `adult`·`ageLimit`·`age_grade>=19`를 모두 적용한다.
2. **웹툰만.** 카카오페이지는 웹소설이 섞여 있으므로 `category=='웹툰'`만 취한다.
3. **중복 제외.** 기존 50편과 제목·작가로 대조해 겹치면 넣지 않는다.
4. **요청 속도 제한.** 초당 3건 이하로 천천히 돌린다. 급하게 긁으면 차단당하고, 그러면 제휴 문의 자체가 우스워진다.


## 4. 저장 방식


- `is_curated = false` — **명작 큐레이션 50편은 손대지 않는다.** 늘어난 작품은 **검색으로만 닿는다.** 홈 인기 5편, 장르 탐색 화면(`renderDiscover`가 `curatedOnly()`를 쓴다)은 지금 그대로다. 검증에서 확인했다.
- `status = '연재'`
- `work_legal_links`에 작품 페이지 딥링크를 함께 넣는다.
- 장르는 각 플랫폼 표기를 사이트 장르 체계(드라마·판타지·스릴러·미스터리·로맨스·액션·코미디·일상·SF·호러)로 매핑한다. 매핑되지 않는 장르는 드라마로 둔다.


## 5. 표지는 수집만 하고 적용은 보류


제휴 문의 문안에 "50편에 표시 중"이라고 적어 보낸다. 회신 전에 1,100편으로 늘리면 받는 쪽 인상이 달라진다.

- 표지 데이터는 수집해서 **별도 SQL 파일로 보관**한다 (`11_covers_expanded.sql`).
- 실행은 제휴 회신 후 대표님 판단으로 미룬다.
- 즉 이번에 반영되는 것은 **작품 목록 + 딥링크 + 장르**까지다.


## 6. 산출물


| 파일 | 내용 | 실행 시점 |
|------|------|-----------|
| `supabase/10_works_expand_serial.sql` | 작품 + 딥링크 + 장르 (표지 없음) | 지금 |
| `supabase/11_covers_expanded.sql` | 확대분 표지 | 제휴 회신 후 |

`09_covers_all.sql`(기존 50편 표지)은 이번 작업과 무관하게 그대로 유효하다.


## 7. 검증 기준


1. 수집 편수와 필터 제외 편수를 로그로 남긴다 — 조용히 누락되는 일이 없게.
2. 딥링크 표본을 실제로 요청해 200 응답을 확인한다.
3. 성인물이 한 건도 섞이지 않았는지 등급 필드로 재확인한다.
4. 헤드리스 브라우저로 검색·장르 화면을 렌더해 깨지는 곳이 없는지 본다.
