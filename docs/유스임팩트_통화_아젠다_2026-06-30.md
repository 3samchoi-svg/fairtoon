# 유스임팩트 대표 통화 아젠다 (2026-06-30)


Fairtoon 프로젝트 컨설팅사(유스임팩트) 대표와의 통화용 아젠다·토킹포인트. 목적은 **진척 점검 + 역할 재정립 합의**.


## 1. 통화 목적 (한 줄)

남은 기간 안에 프로젝트를 완주하기 위해, **홈페이지는 우리(대표님+AI)가 맡아 7월 중 완성**하고, **유스임팩트는 콘텐츠·캠페인을 리드**하는 역할 분담을 제안·합의한다.


## 2. 배경·현황 (공유 사실)

- 유스임팩트와 **1년 프로젝트**, 1월 착수 → 약 6개월 경과.
- 그간 전략을 재정비: 가격비교 중심에서 **'인식 개선 + 합법 이용 안내'** 캠페인으로 방향을 명확히 함(미션 재정의).
- 홈페이지는 기획서를 확정하고 **디자인 시안 다수를 실제 웹으로 배포**해 검토 중인 단계(아직 정식 사이트는 미완).
- 핵심 타깃: 한국에서 불법 웹툰을 보는 **청소년·학생**. 대상은 한국 웹툰.


## 3. 논의 안건


### 안건 A — 방향성·스펙의 현실성

- 우려: 지호가 방향성에 대해 **갈팡질팡**하는 모습이 보이고, 홈페이지에 **현실적이지 않은 스펙**(예: 실시간 가격·전 플랫폼 자동 수집 등)을 계속 넣으려는 경향.
- 우리 입장: 무예산·학생 주도 여건에 맞게 **범위를 현실적으로 고정**해야 한다(핵심 3축 = 디스커버리·합법 안내(어그리게이터)·인식 콘텐츠 / 실시간 데이터는 범위 밖, '최종 확인일' 표기로 운영).
- 요청: 유스임팩트도 지호에게 **일관된 방향·현실적 범위**를 함께 가이드해 달라.


### 안건 B — 일정 우려

- 우려: 6개월이 지났는데 **홈페이지도 아직 안 나왔다.** 남은 기간 안에 완료 가능한지 솔직히 걱정된다.
- 제안: 7월을 **홈페이지 완성 데드라인**으로 못 박고, 이후 일정(8월 검증·공개 → 9~10월 캠페인 확산 → 11~12월 인터뷰·마무리)을 함께 재확인한다.


### 안건 C — 역할 재정립 (핵심 제안)

- 들은 바: 홈페이지 개발은 유스임팩트 지원 없이 **AI를 써서 직접 개발**하기로 했다고 함.
- 제안:
  - **홈페이지 개발 = 대표님 + AI가 주도** → 가급적 **7월 중 완성**.
  - **유스임팩트 = 콘텐츠·캠페인 리드** → 특히 **작가 인터뷰 섭외·진행, 청소년 인식 개선 캠페인 기획·실행**.
- 취지: 각자 가장 잘할 수 있는 영역에 집중해 속도와 완성도를 모두 확보.


### 안건 D — 프로젝트의 본질 재확인

- 홈페이지를 만드는 것이 **프로젝트의 전부가 아니다.** 진짜 가치는 ①작가 인터뷰 ②청소년 불법 웹툰 이용에 대한 **인식 개선 캠페인**.
- 따라서 유스임팩트의 전문성이 **콘텐츠·캠페인 쪽에서 더 크게 발휘**되길 기대.


## 4. 합의하고 싶은 결과 (이 통화의 목표)

1. 홈페이지: **대표님+AI 주도, 7월 완성** 데드라인 합의.
2. 유스임팩트: **작가 인터뷰 + 인식 개선 캠페인 리드** 역할 합의.
3. 남은 6개월 일정·마일스톤 공동 확인.
4. 지호에게 전달할 **일관된 방향·현실적 범위** 공동 가이드.


## 5. 상대에게 던질 질문 (의견 청취)

- 이 역할 분담(홈=우리 / 콘텐츠·캠페인=유스임팩트)에 대해 **유스임팩트 대표님 생각은 어떠신지?**
- 작가 인터뷰 섭외·진행에서 유스임팩트가 **지금 바로 착수 가능한 부분**은 무엇인지?
- 남은 기간 완주를 위해 유스임팩트가 보는 **가장 큰 리스크**는 무엇인지?


## 6. 톤 가이드 (참고)

- **비난이 아니라 협업 재정렬**의 프레이밍 — "누가 못했다"가 아니라 "남은 기간 완주를 위해 역할을 최적화하자".
- 우려는 솔직하게, 제안은 구체적으로. 상대의 전문성(콘텐츠·캠페인)을 존중·인정하는 톤.
- 지호에 대한 지적은 인격이 아니라 **방향·범위 관리** 차원으로 한정.
