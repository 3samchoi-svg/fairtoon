# Fairtoon 경제학 렌즈 콘텐츠 & 수익 유출 카운터 기획

작성일: 2026-07-07 · 작성: 클상무(PM) · 근거: plan.md v2 §6-0 / §4.9-B + 공개통계 리서치(2026-07-07)

> plan.md v2의 대표님 방향 #3(economics 접점)과 #5-B(창작자 수익 유출 카운터)를 구체화한 문서. 모든 수치는 §4의 공개 출처에 근거하며, 카운터·시각화는 "추정"임을 명시한다(측정 정직성 원칙).


## 1. 설계 원칙

- **경제학을 '장식'이 아니라 '뼈대'로.** 각 콘텐츠는 하나의 경제학 개념을 웹툰 사례로 설명한다 → 지호의 economics 포트폴리오·에세이 근거가 된다.
- **무예산·무유지보수·정적.** 모든 콘텐츠는 정적 파일 + 공개 데이터. 인터랙티브는 서버 없는 클라이언트 JS만.
- **신뢰 우선.** 충격적 큰 수치보다 출처가 확실한 공식 수치를 택한다(포트폴리오는 신뢰성이 생명). 모든 수치에 출처·연도 병기.
- **재활용 구조.** 콘텐츠 1편 → 기사 + 데이터 시각화 + 카드뉴스 + 숏폼으로 파생(plan.md §6).


> **집필 주체 = 지호(직접 집필).** 편별 집필 방향·훅·데이터·함정·체크리스트 = `docs/지호_집필가이드_경제학웹툰.md`.


## 2. Part A — "경제학으로 읽는 웹툰" 시리즈 (콘텐츠 메뉴)

플래그십 시리즈. 각 편 = 기사 1 + (시각화 또는 인터랙티브). 난이도·임팩트 순 배열.


### 2-1. 편별 개요

| # | 제목(가안) | 경제학 개념 | 포맷 | 핵심 데이터 |
|---|-----------|-----------|------|-----------|
| 1 | 기다리면 무료는 사실 '가격차별'이다 | 시점 간 가격차별·지불의사 | 기사 + 인터랙티브 슬라이더 | 기다무(카카오 2014~), 24시간 대기 vs 즉시 결제 |
| 2 | 공짜 웹툰의 역설 — 무임승차와 공유지의 비극 | 공공재·무임승차·공유지의 비극 | 기사 + 미니 시뮬레이션 | 불법이용률 20.4%, 작가소득 하락 |
| 3 | 웹툰 1편 결제하면 그 돈은 어디로 가나 | 가치사슬·수익배분·인센티브 | 데이터 시각화(돈의 흐름) | 플랫폼 35~40% / 작가 실수령 |
| 4 | 불법유통의 진짜 비용 | 외부효과·시장실패·과소공급 | 기사 + 시계열 차트 + **카운터(§3)** | 피해 4,465억(2023), 추이 |
| 5 | 왜 알면서도 불법을 볼까 — 넛지의 경제학 | 행동경제·현재편향·마찰·선택설계 | 기사(프로젝트 선언문) | 불법이유 설문(비용 32.8%) |
| 6 | 숫자로 보는 한국 웹툰(대시보드) | 종합·데이터 리터러시 | 정적 데이터 대시보드 | 산업 2.19조 등 종합 |


### 2-2. 편별 상세

**1편 — 기다리면 무료 = 가격차별**
- 논지: '기다무'는 급한 독자는 돈으로, 안 급한 독자는 시간(기다림)으로 값을 치르게 하는 시점 간 가격차별. 경제학 교과서의 price discrimination을 한국 웹툰이 대중화한 사례.
- 인터랙티브: "당신은 얼마를 '기다림'으로 지불하고 있나?" 슬라이더 — 회차·대기시간 입력 → 시간의 기회비용을 원화로 환산(정적 JS).
- 왜 좋은가: 독창적이고 순수하게 흥미로운 각도(계몽 톤 0). 지호 전공 접점이 가장 선명.

**2편 — 무임승차·공유지의 비극**
- 논지: 웹툰은 한 번 만들면 추가 복제비용이 0에 가까운 준(準)공공재 → 무임승차 유인이 큼. 모두가 무임승차하면 창작 유인이 무너져 '볼 작품' 자체가 줄어드는 공유지의 비극.
- 미니 시뮬레이션: 무임승차 비율 슬라이더 → 창작자 생존/신작 수가 줄어드는 시각화(정적 JS, 단순 모델·가정 명시).
- 데이터: 불법이용률 20.4%(2023), 연재작가 소득 하락(8,540만원, 2023).

**3편 — 돈의 흐름 해부**
- 논지: 독자가 낸 1,000원이 플랫폼·CP·작가로 갈라지는 경로. "합법 결제가 왜 창작자에게 의미있나"를 감정이 아니라 구조로 설명.
- 시각화: 결제액 → 플랫폼(35~40%) → CP → 작가 실수령까지 막대/생키. CP 경유 시 작가 몫이 급감하는 구조 대비.
- 데이터: KOCCA 배분 비율, 작가 실수령 관찰치.

**4편 — 불법유통의 진짜 비용 (카운터 탑재)**
- 논지: 불법유통 = 창작자에 대한 부의 외부효과 → 시장실패 → 콘텐츠 과소공급. '개인의 공짜'가 사회적 손실로 전이.
- 구성: 시계열 차트(피해 추이) + **창작자 수익 유출 카운터(§3)** 를 이 기사 상단에 배치.
- 데이터: 피해 4,465억(2023, KOCCA) / 추이 3,932억(2022)→4,465억(2023).

**5편 — 넛지의 경제학 (프로젝트 선언문)**
- 논지: 사람들이 불법을 보는 건 도덕이 아니라 '마찰'과 현재편향 탓(지금·공짜가 이김). 마찰을 줄이면 선택이 바뀐다 → **그래서 우리는 '검색 패스스루'라는 넛지 도구를 만들었다.**
- 이 편이 지호 에세이의 심장: "사회문제를 경제학으로 진단하고, 행동경제학적 개입 도구를 직접 설계·구현했다."
- 데이터: 불법 이유 설문(비용부담 32.8%, 가치없다 12.2%).

**6편 — 데이터 대시보드**
- 한 페이지 정적 대시보드(Our World in Data 톤, plan.md 홈시안 G 계열과 연결): 산업규모 2.19조 / 불법피해 4,465억 / 불법이용률 20.4% / 작가소득 추이. 모든 카드에 출처·연도.
- 유지보수: 연 1회 KOCCA 신규 보고서 나오면 숫자만 갱신(선택). 안 해도 "2023 기준"으로 정직.


## 3. Part B — 창작자 수익 유출 카운터 상세 스펙

plan.md §4.9-B. 서버 없이 순수 클라이언트 JS로 구현, 방치해도 굴러감.


### 3-1. 무엇을 보여주나

불법유통으로 창작자에게 가지 못하고 새어나가는 **추정 금액**이 실시간으로 증가하는 티커.


### 3-2. 앵커 수치 (권장: 공식·보수적)

- **연 4,465억 원** — 2023년 웹툰 불법복제 피해규모, 한국콘텐츠진흥원 『2024 웹툰산업 실태조사』.
- 대안(더 큰 임팩트): 연 8,427억 원(2021, 문체부). 단 방법론이 달라(피해액 vs 불법시장 규모) 혼용 금지. **포트폴리오 신뢰성 위해 4,465억 권장.**


### 3-3. 산식 (초 단위 환산)

- 4,465억 ÷ (365×24×3600초 = 31,536,000초) ≈ **14,159원/초**
- ≈ 84.9만원/분 · ≈ 5,097만원/시간 · ≈ 12.2억원/일
- 순수 시간함수 → 서버 불필요, 영구 자동 작동.


### 3-4. 표시 모드 (2가지, 배치처별)

- **(a) 세션 카운터 — "당신이 이 글을 읽는 동안"** : 페이지 로드 시점부터 경과초 × 14,159원. 30초면 ≈ 42만원. 가장 강렬·공유성 높음 → 홈 인식 후크·Stay Safe·4편 상단.
- **(b) 연간 누적 — "올해 들어 지금까지"** : 1월 1일 0시부터 경과초 × 14,159원. 큰 숫자·데이터 톤 → 6편 대시보드. 매년 자동 리셋(날짜 계산만, 유지보수 0).


### 3-5. 경제학 연결 & 등가 환산 (선택 토글)

- 원화 대신 의미 단위로도 표시: 4,465억 ÷ 작가 연소득 8,540만원 ≈ **작가 약 5,200명의 1년 소득**.
- 카피 예: "지금 이 손실은 웹툰 작가 약 5,200명의 1년 벌이와 맞먹습니다." → 외부효과(4편)와 연결.


### 3-6. 정직성 장치 (필수)

- 라벨 고정 표기: "**추정치** — 한국콘텐츠진흥원 2023년 웹툰 불법복제 피해규모(연 4,465억 원)를 초 단위로 환산. 실시간 실측이 아닙니다."
- 출처·산식은 펼침(더보기)으로 공개. 정밀 실시간인 척하지 않는다.


### 3-7. 구현·유지보수

- 순수 HTML+JS. 앵커 금액·출처를 파일 상단 상수로 분리 → 연 1회 숫자만 바꾸면 갱신(안 바꿔도 "2023 기준"으로 정직). 스크레이핑·서버·정기작업 일절 없음.

## 5. 대표님 결정 필요사항

1. **카운터 앵커** — (권장) 공식·보수적 4,465억 / (대안) 임팩트 큰 8,427억. → 신뢰성 위해 4,465억 권장.
2. **카운터 표시 모드** — (권장) 세션형 "읽는 동안" + 대시보드에 연간형 병행 / 하나만.
3. **시리즈 편수·우선순위** — 6편 전체 로드 vs 출시 시 핵심 3편(1·4·5편 권장) 먼저.
4. **인터랙티브 범위** — 1편 슬라이더·2편 시뮬은 개발 공수가 조금 더 듦. 출시엔 카운터만 넣고 인터랙티브는 후속으로 돌릴지.
