# Fairtoon 디자인·테마 참조 사이트

작성일: 2026-07-19 · 작성: 클상무(PM)
근거: `docs/plan.md` v2 디자인 원칙(밝은 테마 · Archivo Black+Inter · 블루 #2F5FEF 액센트 · pill · 둥근 카드 · 깔끔한 검색바) + 홈 시안 7종(`/sian/` A~I) + 2026-07-19 대표님 요청

> fairtoon은 단순 갤러리가 아니라 ①검색 디스커버리 ②인식 개선 허브 ③경제학 데이터 렌즈 ④학생 타깃을 겸한다. 그래서 참조도 이 4개 성격을 나눠 본다. 각 사이트는 "무엇을 훔칠지"를 명시했다.


## 1. 검색 중심 · 유틸리티 홈 (검색 패스스루 · 홈 히어로)

작품명 하나로 시작하는 fairtoon의 검색 우선 동선에 직접 대응. 홈 시안 A(Spotlight)·C(Index) 계열.

- **Perplexity** — https://www.perplexity.ai · 검색바 하나로 페이지 전체가 서는 미니멀 홈. "입력 → 결과"의 절제된 진입.
- **Linear** — https://linear.app · 밝은/다크 겸용, 타이포·여백·라운드·미세 그라데이션의 완성도. 제품 랜딩 벤치마크.
- **DuckDuckGo** — https://duckduckgo.com · 군더더기 없는 검색 홈 + '가치(프라이버시)'를 얹은 검색엔진. fairtoon = 검색 + 가치(합법)와 구조가 같음.
- **Algolia** — https://www.algolia.com · 검색 UX 그 자체의 레퍼런스(자동완성·결과 표현).


## 2. 웹툰·OTT 디스커버리 (명작 큐레이션 · 카드 진열)

표지 카드·태그·큐레이션 리스트의 톤. 홈 시안 D(OTT)·E(따뜻한 서재) 계열.

- **라프텔** — https://laftel.net · 국내 애니 디스커버리. 태그·테마 큐레이션, 완결작 정주행 UX가 fairtoon 명작 큐레이션과 가장 유사.
- **왓챠피디아** — https://pedia.watcha.com · 작품 디스커버리 + 평점·코멘트·컬렉션. 메타데이터 카드 설계 참조.
- **Letterboxd** — https://letterboxd.com · '리스트/큐레이션 문화'의 정수. "합법으로 보는 숨은 명작" 같은 테마 모음의 롤모델.
- **네이버웹툰** — https://comic.naver.com · 타깃 사용자가 매일 보는 화면. 카드 밀도·요일 진열의 기준선(넘어야 할/맞춰야 할 관습).
- **Netflix** — https://www.netflix.com · 진열·호버·몰입 톤(단, fairtoon은 더 밝고 가벼워야 함).


## 3. 데이터 저널리즘 · 경제학 렌즈 (아티클 · 수익 카운터 · 6편 대시보드)

'경제학으로 읽는 웹툰' 아티클, 수익 유출 카운터, 숫자 대시보드의 톤·신뢰성. 홈 시안 G(데이터 투명성) 계열.

- **Our World in Data** — https://ourworldindata.org · 차트+서술+출처 병기의 표준. 정직성 장치(추정·연도·출처)와 데이터 대시보드(6편)의 직접 모델.
- **The Pudding** — https://pudding.cool · 인터랙티브 비주얼 에세이. 1편(가격차별 슬라이더)·2편(무임승차 시뮬) 같은 '읽으며 만져보는' 아티클의 롤모델.
- **The Upshot (NYT)** — https://www.nytimes.com/section/upshot · 경제·사회 데이터를 대중 언어로. 서술 톤 참조.
- **Information is Beautiful** — https://informationisbeautiful.net · 데이터 시각화 미학(카드뉴스·시각화 파생물에 유용).


## 4. 인식·캠페인 · 대의(cause) 설득 (인식 허브 · 넛지 서사)

"왜 합법이어야 하나 → 그럼 여기서 바로"의 설득·행동 유도 구조.

- **charity: water** — https://www.charitywater.org · 대의를 감성이 아니라 '투명한 숫자·임팩트'로 설득. 진정성 톤(포트폴리오 성격에 부합).
- **Stripe(브랜드/문서)** — https://stripe.com · '복잡한 것을 신뢰감 있게 설명'하는 카피·레이아웃. 경제 개념을 어렵지 않게 전달하는 서술 벤치마크.
- **Apple 개인정보 보호** — https://www.apple.com/privacy · '개인 위험'을 위협적이지 않게, 세련되게 경고. Stay Safe(안전 수칙) 페이지 톤.
- **Do the Green Thing / 공익 캠페인류** — https://www.dothegreenthing.com · 훈계 대신 위트로 태도를 바꾸는 캠페인 화법(학생 타깃 톤 참고).


## 5. Z세대 · 영 브랜드 · 게임화 (학생 톤 · 취향 테스트 · 바이럴)

또래 눈높이, 재미 요소(취향 테스트), 숏폼 바이럴 후크. 홈 시안 B(Playground)·I(Z세대 매거진) 계열.

- **Dazed** — https://www.dazeddigital.com · Z세대 컬처 매거진. 과감한 타이포·편집 감각(아티클/작가의 목소리 편집 톤).
- **Duolingo** — https://www.duolingo.com · 학생 친화·게임화·마스코트. 취향 테스트(§4.9-A)의 재미·전환 설계 모델.
- **Gumroad** — https://gumroad.com · 컬러풀·플레이풀하면서도 정리된 브랜드. 밝은 테마의 '노는' 버전.
- **NSS Magazine** — https://www.nssmag.com · 영 컬처 편집 디자인 참조.


## 6. 타이포·미니멀 시스템 (Archivo Black + Inter · 인덱스형)

디스플레이 폰트 + 본문 산세리프 + 블루 1단어 액센트 시스템의 정련. 홈 시안 C(Index) 계열.

- **Vercel** — https://vercel.com · 극단적 미니멀 + 강한 타이포 + 절제된 액센트. 밝은 테마 시스템의 교과서.
- **Stripe Press** — https://press.stripe.com · 세리프/산세리프 조합·여백·품격. '진지한 콘텐츠'의 밝은 표현.
- **Family New York** — https://family.co · 초대형 타이포·과감한 여백(Archivo Black 활용 아이디어).


## 7. 영감 갤러리 (계속 참고할 소스)

특정 사이트가 아니라, 매번 새 레퍼런스를 뽑을 상시 소스.

- **Awwwards** — https://www.awwwards.com/websites/minimal/ · minimal·typography·clean 컬렉션.
- **Godly** — https://godly.website · 큐레이션된 고퀄 웹 디자인.
- **Land-book** — https://land-book.com · 랜딩페이지 특화 갤러리.
- **Mobbin** — https://mobbin.com · 실제 앱/웹 UI 패턴 아카이브(검색·온보딩·카드 패턴 참조).
- **SiteInspire** — https://www.siteinspire.com · 카테고리별 정제된 갤러리.


## 8. 요약 — fairtoon에 어떻게 적용하나

| fairtoon 요소 | 1순위 참조 |
|---|---|
| 홈 히어로·검색 패스스루 | Perplexity · Linear |
| 명작 큐레이션 카드 | 라프텔 · Letterboxd · 왓챠피디아 |
| 경제학 아티클·수익 카운터·대시보드 | Our World in Data · The Pudding |
| 인식 허브·설득 톤 | charity:water · Stripe |
| 안전 수칙 | Apple 개인정보 보호 |
| 취향 테스트·학생 톤 | Duolingo · Dazed |
| 타이포·미니멀 시스템 | Vercel · Stripe Press |

- 방향 원칙: **밝고 가볍게(넷플릭스·다크 톤은 피함) + 진지한 신뢰(데이터 저널리즘) + 또래 위트(Z세대)** 의 삼각 균형. 어느 하나로 쏠리면 포트폴리오 신뢰성 또는 학생 도달력이 무너진다.
- 다음 단계 제안: 위 중 대표님이 '느낌 오는' 3~5개를 고르시면, 그 요소를 현재 라이브(v2)에 반영해 방향을 좁혀갑니다.
