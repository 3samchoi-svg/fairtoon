### ③ 딥링크 — 해결 완료

이전에는 50편 중 1편(미생)만 작품 페이지로 연결됐고 나머지는 검색 결과 페이지로 보내고 있었습니다. **50편 전부 작품 페이지 직행으로 교체**했습니다. 위 4번 항목은 더 이상 검수하지 않으셔도 됩니다.



## 검수해 주실 것

1. **연재 플랫폼** — 가장 중요합니다. 실제로 그 플랫폼에서 볼 수 있는지.
2. **작가명** — 글/그림 작가가 다른 경우 특히.
3. **연재 상태** — 완결/연재.
4. **딥링크(선택)** — 작품의 정확한 주소를 알려주시면 검색 결과가 아니라 작품 페이지로 바로 연결됩니다.
   예) 미생 → https://webtoon.kakao.com/content/미생/818?tab=episode

수정 방법은 두 가지입니다. 편하신 쪽으로 하십시오.
- **직접 수정**: 관리자 페이지(/admin) → 작품 탭 → 해당 작품 수정
- **알려주시기**: 틀린 항목만 정리해 주시면 PM이 일괄 수정 SQL을 만들어 반영합니다

## 참고

- **소개 문구**는 PM이 작성했습니다. 톤이 안 맞으면 관리자 페이지에서 바로 고치실 수 있습니다.
- **표지 이미지**는 아직 없습니다(색상 그라데이션 표시). 저작권 문제로 임의 사용이 어려워 별도 방안을 검토 중입니다.
- **리디**: 리디에도 완결 웹툰이 있다는 점을 대표님이 확인해 주셨습니다(예: 황제와 여기사). 현재 작품 DB에 리디 작품이 한 편도 없으니, 추후 확대 시 리디 작품을 함께 담겠습니다.
- 딥링크가 없는 작품은 해당 플랫폼의 **검색 결과**로 연결됩니다. 동작에는 문제없지만 딥링크가 더 정확합니다.
