## 2. 공통 문안 (네이버웹툰 발송본)


**제목**

```
[제휴 문의] 불법 웹툰 근절 캠페인 사이트의 작품 표지 이미지 이용 허락 요청 (고등학생 제작 · 비영리)
```

**본문**

```
안녕하십니까.

고등학생 최지호라고 합니다. 불법 웹툰 유통을 줄이기 위한 캠페인 웹사이트
'페어툰(Fairtoon, https://fairtoon.com)'을 직접 만들어 운영하고 있습니다.

■ 사이트를 만든 이유

또래 친구들이 불법 사이트에서 웹툰을 보는 것을 자주 봤습니다. 나쁜 마음이라기보다
어디서 정식으로 볼 수 있는지 모르거나, 막연히 비쌀 것이라 짐작해서인 경우가
대부분이었습니다. 실제로는 무료 회차나 기다리면 무료 같은 방법이 있는데도 그렇습니다.

그래서 "이 작품, 어디서 정식으로 볼 수 있나"를 한 번에 알려주는 사이트를 만들었습니다.
작품명을 검색하면 정식 연재처로 바로 연결해 주고, 불법 사이트가 창작자에게 어떤
피해를 주는지를 함께 설명합니다.

■ 사이트의 성격

- 비영리입니다. 광고를 붙이지 않고, 어떤 수익도 발생하지 않습니다.
- 작품을 저희 사이트에서 보여주지 않습니다. 이용자를 귀사 서비스로 보내는 것이
  유일한 목적이며, 모든 작품 카드는 귀사의 작품 페이지로 직접 연결됩니다.
- 청소년 단체 유스임팩트와 함께 진행하는 공익 프로젝트입니다.

■ 요청 드리는 것

작품 카드에 해당 작품의 대표 이미지(표지)를 표시할 수 있도록 허락을 요청드립니다.

표지가 없으면 이용자가 작품을 알아보지 못해, 정식 연재처로 연결한다는 사이트의
목적 자체가 약해집니다. 저희가 자체 제작한 이미지로 대체해 보았으나, 오히려
작품을 잘못 전달할 우려가 있어 정식으로 허락을 구하는 편이 옳다고 판단했습니다.

이용 방식은 아래와 같이 최소한으로 제한하겠습니다.

1. 귀사가 링크 공유용으로 제공하는 대표 이미지(og:image)를 참조합니다.
   이미지를 저희 서버에 복제하거나 저장하지 않습니다.
2. 카드 크기(가로 200px 내외)로만 표시하며, 원본 해상도로 확대해 보여주지 않습니다.
3. 이미지에 '(c) 네이버웹툰' 출처를 표기합니다.
4. 이미지를 클릭하면 귀사의 해당 작품 페이지로 이동합니다.
5. 귀사가 원하시는 표기 문구나 표시 방식이 있다면 그대로 따르겠습니다.

■ 현재 상태를 먼저 말씀드립니다

회신을 기다리는 동안 사이트가 비어 보이지 않도록, 현재 소개 중인 작품
50편에 대해 위 1~4번 방식으로 표지를 표시하고 있습니다. 이 가운데 귀사
연재작은 29편입니다. 미리 말씀드리지 않고 시작한 점 양해 부탁드립니다.

만약 이 방식이 부적절하다고 판단하시면 회신 주시는 즉시 내리겠습니다.
내리는 작업은 설정 한 줄만 지우면 되며, 저희가 대체 이미지를 이미 준비해 두어
사이트 운영에 지장이 없습니다. 조건부 허락이나 부분 허락도 좋습니다.

■ 함께 제안드리고 싶은 것

혹시 가능하다면, 정식 연재처로 이용자를 보내는 이 캠페인에 대해 귀사에서
공식적으로 협력해 주실 수 있는 방법이 있는지도 여쭙고 싶습니다. 표지 이미지
제공 방식이든, 캠페인 소개든, 저희가 맞출 수 있는 부분은 맞추겠습니다.

학생이 만든 사이트라 부족한 점이 많습니다. 그래도 웹툰을 정식으로 보는 사람이
한 명이라도 늘었으면 하는 마음으로 만들었습니다. 검토해 주시면 감사하겠습니다.
```

## 4. 리디 발송본 — 수정 지점


리디는 현재 표지를 쓰고 있는 작품이 없으므로 성격이 다릅니다.

- "■ 현재 상태를 먼저 말씀드립니다" 문단 **전체 삭제**
- 대신 다음으로 대체:

```
■ 현재 상태

리디 작품은 아직 저희 사이트에 등록돼 있지 않습니다. 앞으로 작품을 늘릴 때
리디 연재작을 포함할 계획이며, 그 전에 표지 이용 방식을 먼저 여쭙는 것이
순서라고 생각해 미리 문의드립니다.
```

- 출처 표기 예시 → **`(c) 리디`**
- 리디는 웹소설·전자책 비중이 크므로, "웹툰뿐 아니라 정식 연재·판매처 전반을 안내한다"는 점을 한 줄 덧붙이면 접점이 넓어집니다


## 5. 회신 처리 방침 (미리 정해둘 것)


| 회신 유형 | 대응 |
|-----------|------|
| 허락 | 해당 플랫폼 작품 전체로 표지 확대 적용. 요구 표기 방식이 있으면 그대로 반영 |
| 조건부 허락 | 조건 그대로 수용. 크기·표기·링크 제약은 모두 수용 가능한 범위 |
| 거절 | **즉시 철회.** `supabase/09_covers_all.sql` 하단 철회 스크립트 실행 → 장르 커버로 자동 복귀. 플랫폼 단위 철회도 같은 파일에 준비돼 있다 |
| 무응답 (4주 경과) | 대표님께 재보고 후 판단. 무응답을 묵시적 허락으로 해석하지 않는다 |
