# 05 · 데이터·검색 DB


검색 기능의 데이터를 어떻게 구조화·소싱·최신화하는지 정리합니다. 목표 DB 규모는 **150~300편**(현재 약 10편 수집).


## 검색 결과 DB — 현재 상태

시트는 **행 = 속성, 열 = 시리즈** 구조입니다. 현재 **10편** 등록:

1. Solo Leveling (나 혼자만 레벨업)
2. Tower of God (신의 탑)
3. Omniscient Reader's Viewpoint (전지적 독자 시점)
4. The God of High School (갓 오브 하이스쿨)
5. Noblesse (노블레스)
6. True Beauty (여신강림)
7. Lookism (외모지상주의)
8. Sweet Home (스위트홈)
9. Weak Hero (약한영웅)
10. Eleceed (엘리시드)

### 컬럼(속성) 그룹 및 채움 상태

| 그룹 | 속성 | 상태 |
|------|------|------|
| 핵심 정보 | 제목, 표지, 작가, 작화, 퍼블리셔, 연재기간, 상태, 연재스케줄, 총/현재 화수 | 표지 전부 공란("-"), 나머지 채워짐 |
| 합법 플랫폼 | 한국어, 영어 | 채워짐 (지역/가격 등 상세 컬럼은 시트에 아직 없음) |
| 장르·콘텐츠 정보 | 주요 장르 태그, 카테고리 태그, 콘텐츠 경고, 연령 등급, 줄거리 | 채워짐 |
| 평점·반응 | 평점&랭킹, 커뮤니티 반응, 수상 | 평점&랭킹만 채워짐, 반응·수상은 **공란** |
| 기타 | 각색, 유사 작품 | **전부 공란** |

**샘플 (Solo Leveling):** 작가 Chugong · 작화 장성락(DUBU) / REDICE STUDIO · 퍼블리셔 D&C미디어(KR) / Yen Press(EN) · 연재 2018.3.4 – 2021.12.29 · 완결 · 본편 179 + 외전 21 = 200 · KR: 카카오페이지, 카카오웹툰 · EN: Tapas, Tappytoon, Manta · AniList 84%(역대 인기 만화 #2) · MangaUpdates 약 8.6/10 · 연령 Teen+(13+).

대부분 네이버(KR) / Webtoon Entertainment(EN) 퍼블리셔로 WEBTOON(LINE Webtoon)에 연재되며, Solo Leveling만 카카오 계열 예외. 최고 평점: Eleceed·Weak Hero AniList 88%; ORV MangaUpdates 약 8.8/10.

> 즉 시트는 상세페이지 명세 중 일부만 구현된 상태 — 표지, 커뮤니티 반응, 수상, 각색, 유사 작품은 아직 수집 중.


## 데이터 소싱 — 하이브리드 방식

- 기존 **API**에서 일반 메타데이터 pull + 필요한 부분은 스프레드시트에 수동 수집/저장.
- 가변 데이터(평점, 인기 랭킹) → API. 정적 데이터(장르, 작가) → API 또는 수동.
- **API:** AniList API · MangaUpdates API · Kitsu API · 공식 플랫폼.


## 데이터 최신화 — 모니터링

변경 감지 소스: 공식 플랫폼 뉴스레터/공지, 공식 Twitter/X, Reddit(r/webtoons, r/manhwa), Google Alerts 키워드, 그리고 월간 URL 검증 + 사이트의 "Report an Issue" 기능.

### 추적할 변경 유형

| 레벨 | 예시 |
|------|------|
| 플랫폼 레벨 (고우선) | 플랫폼 폐쇄(Tapas 재정 주시), 인수합병, 도메인/URL 구조 변경(전체 링크 깨짐), 가격모델 변경, 신규/제한 지역, 리브랜딩 |
| 시리즈 레벨 (최빈) | 신규 라이선스, 플랫폼 제거/이동, 지역잠금, 무료↔유료 전환, 동시연재; 휴재/재개/완결/취소/리메이크; 영문 제목 변경, 작가·작화 교체, 장르 재분류 |
| URL 레벨 | 페이지 URL/슬러그 변경, HTTP→HTTPS, 서브도메인 이동 |
| 비즈니스/법률 | 라이선스 만료 후 미갱신(무공지 소멸), 법적 분쟁, 지역 권리 상실, 비공식→공식 전환, 작가 자가출판 |
| 놓치기 쉬운 것 | 조용한 삭제, 소프트 페이월(예: 앞 20화만 무료), 무공지 지역 차단, 깨진 embed/redirect |

### 모니터링 우선순위 Tier

- **High(즉시):** 플랫폼 폐쇄/인수, URL 구조 변경, 상위 50개 검색 시리즈에 영향
- **Medium(1주 내):** 개별 시리즈 제거/이동, 가격모델 변경, DB 내 시리즈의 신규 라이선스
- **Low(1개월 내):** 상태 변경(휴재/완결), 메타데이터 변경, DB 미포함 시리즈의 신규 라이선스

| 대분류 | 모델 | 설명/예시 |
|--------|------|-----------|
