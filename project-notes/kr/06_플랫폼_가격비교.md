# 06 · 플랫폼 가격 비교


주요 **한국** 웹툰 플랫폼의 가격/수익 모델 상세입니다. 각 작품 상세페이지의 "합법 플랫폼" 비교를 채우는 데 사용됩니다. 영어권 플랫폼 모델은 원본에서 **미정**(플레이스홀더만 존재).


## 한눈에 보기

| 플랫폼 | 결제 화폐 | 핵심 무료/대여 수단 |
|--------|-----------|---------------------|
| 네이버 웹툰 | Cookies | 무료대여권, 광고보고무료, 몰아보기 1시간권 |
| 네이버 시리즈 | Cookies | 프리패스, 타임딜, 매일10시 무료, 광고보고무료 |
| 카카오 웹툰 | Cash(캐시) | 시간마다 무료, 선물함, 자동충전 |
| 카카오페이지 | Cash(캐시) | 기다리면 무료(기다무), 기다무+, 선물함, 세트 구매 |


## 네이버 웹툰 — 화폐: Cookies

**무료/대여 수단**
- **무료대여권:** 24시간마다 n개 지급. 1화를 3일 대여. 최대 n개 보관. 최신화는 사용 불가할 수 있음.
- **광고보고무료:** 광고 시청 후 1화 3일 대여. 매일 자정 n개로 리셋. 최신화 제외될 수 있음.
- **몰아보기 1시간권:** 1시간 동안 전 회차 무료 열람. 쿠키로 구매.

**작품 상태별**
- **연재중:** *Normal Release* — 매주 지정 요일에 1화씩 추가 무료(최신화 기준 3~5화 뒤); 새로 풀린 화와 이전 화 모두 무료. *미리보기* — 미래 회차를 대여/구매.
- **완결:** n개 무료 선공개 / 대여(3일)·소장 / 무료대여권(일부) / 광고보고무료(일부) / 몰아보기 1시간권(일부).
- **매일+:** n개 무료 선공개 / 대여(3일)·소장 / 무료대여권(일부) / 광고보고무료(일부).


## 네이버 시리즈 — 화폐: Cookies

네이버 웹툰과 달리 모든 모델이 **작품 상태와 무관하게** 적용.

- **n개 무료 선공개 회차**
- **대여(3일) / 소장**
- **프리패스**(일부 작품): 1화 3일 대여. 프리패스 수는 적용 작품 전체에 **공유되는 static 변수** — 최대 6개, 2시간마다 1개 충전; 최신화 제외될 수 있음.
- **타임딜:** 짧은 기간 대량 선행 회차 무료.
- **매일10시 무료:** 클릭 시 일정 기간 매일 밤 10시에 3일 대여권 n개 지급; 받은 후 24시간 내 사용; 최신화 제외될 수 있음.
- **광고보고무료:** 광고 시청 후 1화 3일 대여; 매일 자정 n개 리셋.


## 카카오 웹툰 — 화폐: Cash(캐시)

**무료/대여 수단**
- **시간마다 무료 / 기다리면 무료:** 1화 열람 시점부터 설정 대기시간(예: 3/12/24시간) 후 무료대여권 1개; 1화 3일 대여; 최대 1개 보관; 최신화 제외될 수 있음.
- **선물함:** 특정 작품에 3일 무료대여권 또는 캐시 추첨권을 주기적으로 지급; 만료 전 사용.
- **자동충전:** 캐시 자동충전 시 보너스 캐시(최대 10%) 적립 → 회차당 실질 비용 인하.

**작품 상태별**
- **연재중:** Normal Release(주 1화 추가 + 일부 과거 회차 무료) / 유료 미리보기(대여·소장권으로 선행 구매) / 시간마다 무료(대기 후 잠긴 과거 회차 순차 해금).
- **완결:** n개 무료 선공개 / 대여(3일)·소장 / 시간마다 무료(일부) / 선물함(일부).


## 카카오페이지 — 화폐: Cash(캐시)

**무료/대여 수단**
- **기다리면 무료(기다무):** 1화 열람 정확한 시점부터 설정 대기시간(예: 3/8/12/24시간·3일) 후 무료대여권 1개; 1화 3일 대여; 작품당 최대 1개; 최신화 제외될 수 있음.
- **기다무 플러스(기다무+):** 선정된 작품 풀에 12시간마다(보통 0시·12시 고정) 무료대여권 5개 자동 지급; 최대 5개, 누적 안 됨; 1화 3일 대여.
- **선물함:** 프로모션 작품에 3일 무료대여권을 주기적으로 지급; 만료 전 수령·사용.
- **세트 구매:** 작품/권 단위 대여·소장권 묶음 구매 시 할인(보통 10~30% off).

**작품 상태별**
- **연재중:** Normal Release(주 1화 추가 + 기준 회차 무료) / 미리보기(캐시로 대여·소장권 개별 구매) / 기다무(무료 풀과 최신 미리보기 사이 중간 회차를 대기 타이머로 순차 해금).
- **완결:** n개 무료 선공개 / 대여(3일)·소장 / 기다무(일부) / 기다무+(일부) / 선물함(일부) / 세트 구매.


## 비교 결론

- **화폐 차이:** 네이버 계열 = Cookies / 카카오 계열 = Cash(캐시).
- **상태 의존성:** 네이버 웹툰·카카오 웹툰·카카오페이지는 가격모델이 **연재 상태(연재중/완결)에 의존**. 반면 **네이버 시리즈는 상태 무관**으로 전 모델 적용 — 이것이 시리즈의 구조적 차별점.
- **무료 대여 충전 메커니즘:**
  - 네이버 웹툰: 24시간마다 다수(n개).
  - 네이버 시리즈 프리패스: 2시간마다 1개, 최대 6개, **작품 간 공유**.
  - 카카오 웹툰/페이지 기다무: 작품당 최대 1개.
  - 카카오페이지 기다무+: 12시간마다 5개(고정 시각).
- **실질 비용 인하 수단:** 카카오 계열에만 존재 — 자동충전 보너스 캐시(최대 10%, 카카오웹툰), 세트 구매 할인(10~30%, 카카오페이지).
- **공통 제약:** 모든 무료/대여 수단에서 **"최신 회차는 접근 불가할 수 있다"**가 반복 — 최신화는 유료 우선 수익화.


## 미결정 항목

- **영어권 플랫폼**(WEBTOON, Tapas, Tappytoon, Lezhin, Manta 등): 원본 섹션은 플레이스홀더(`asdf`)만 있음. FairToon이 추후 채울 계획. 분류 틀은 [05 · 데이터·검색 DB](./05_데이터_검색DB.md)의 가격모델 체계가 이미 제공.
