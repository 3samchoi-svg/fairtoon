# 02 · 프로젝트 계획·타임라인


초기 로드맵(2025년 초 작성)은 기초 기획부터 출시까지 진행한 뒤, 반복 성장 사이클로 들어갑니다.


## 타임라인 (2025)

| 단계 | 기간 | 목표 |
|------|------|------|
| 린 캔버스 & 피치덱 | 1/13 – 2/2 | 기초 프로젝트 계획 + 프로젝트 윤곽을 잡는 피치덱 |
| 웹사이트 프로토타입 디자인 | 2/2 – 2/16 | 개발자가 구현할 프로토타입 디자인 — 구조·기능·표시 윤곽 |
| 초기 데이터 수집 | 2/16 – 3/9 | 불법복제 피해 핵심 데이터 수집, 그래프/차트 분석 (확정본 아님, 프로토타입용) |
| 웹사이트 프로토타입 개발 | 3/9 – 3/30 | 디자인 + 초기 데이터 기반 실제 프로토타입 제작 |
| 추가 데이터 수집·분석 | 3/9 – 3/30 | 사이트 제작 중 정제용 데이터 추가 수집 |
| 웹사이트 정제 | 3/30 – 4/13 | 신규 데이터 기반 정제, 프로토타입 오류 수정 |
| 바이럴 콘텐츠 기획 | 3/30 – 4/13 | 사이트 홍보·인식 확대를 위한 바이럴 마케팅 기획 |

| 웹사이트 확정·출시 | 5/4 – 5/18 | 피드백 반영 확정, 크리에이터 인터뷰 추가 |


## 반복 사이클 (출시 후)

출시 후에는 다음을 지속 반복합니다.

1. 웹사이트 홍보·광고
2. 바이럴 콘텐츠 제작
3. 추가 데이터 수집·분석
4. 웹사이트 정제


## 현재 진행 상태 (PM 메모, 2026-06)

위 2025 타임라인은 **초기** 계획입니다. 2026년 중반 현재 프로젝트는 그보다 훨씬 진전되어 있습니다.

- 웹사이트 컨셉이 **재설계**됨 (→ [04 · 웹사이트 기획](./04_웹사이트_기획.md), 캠페인형 → 검색엔진 우선형으로 전환).
- 최신 기획 기반의 **웹사이트 프리뷰**가 동작 중 (저장소 루트의 단일 파일 `index.html`, GitHub Pages 배포).
- 데이터 수집은 **진행중**: 검색 DB에 현재 약 10편 등록(목표 150~300편).

본 문서는 초기 로드맵을 보존하며, 현재 실행 상태는 `docs/plan.md`·`docs/progress.md`에서 관리합니다.
