# 01 · 프로젝트 개요


## FairToon이란

FairToon은 **웹툰 불법복제로 인한 피해를 수집·분석·시각화**하고, 독자를 합법 플랫폼으로 유도해 불법 사이트 사용을 줄이는 것을 목표로 하는 웹사이트입니다.

2025년 1월, 청라달튼외국인학교 고등학교 2학년 최지호 학생의 개인 프로젝트로 시작되었으며, 대학 지원용 포트폴리오 성격도 갖습니다. **마케팅 예산이 없는** 독립 프로젝트라는 점이 전략 전반을 규정합니다(유료 광고 대신 오리지널 콘텐츠와 SEO 중심).


## 미션과 포지셔닝

원본에 별도의 공식 미션 문구는 없으나, 모든 문서에서 의도는 일관됩니다.

> 대중 인식을 높여 불법 웹툰 사이트 사용을 줄이고 — 동시에 **합법** 경로를 충분히 편리하게 만들어 불법복제의 주된 이점을 없앤다.


## 핵심 전략 — 훈계가 아닌 '자기 이익'

가장 핵심적인 전략적 결정은 메시지를 **어떻게** 프레이밍하느냐입니다.

- 도덕적 훈계가 **아님** ("불법복제는 창작자를 해치니 그만둬라").
- 대신 **자기 이익 기반** 프레이밍("불법 사이트는 *당신*과 *당신 기기*에 위험하다") + 합법 대안을 정말 더 쉽게 만들기.

그래서 사이트는 순수 액티비즘 캠페인이 아니라, **실용 도구**(해당 작품을 어디서 합법으로 볼지 찾기)와 **인식 콘텐츠**(불법복제가 왜 위험한지)를 결합합니다.


## 타깃 사용자 (2개 층위)

| 층위 | 대상 | 유입 경로 |
|------|------|-----------|
| 1차 | 이미 합법으로 보고 싶은 독자 | **검색(Search)** 기능으로 직접 해결 |
| 2차 | 사이트 존재를 모르는 독자 | **SEO / 기사(Articles)**로 유입 (예: "웹툰 불법 사이트 안전한가" 검색 → 기사 랜딩 → 사이트 발견) |


## 목표

1. 웹툰 작품의 **합법 플랫폼 파인더**(위키형)를 유용하게 구축.
2. **오리지널·SEO 친화 콘텐츠**(기사)로 오가닉 발견을 유도.
3. 합법 이용의 진입장벽을 낮추고 **동시에** 불법복제의 개인적 위험을 알려 사용을 줄임.
4. **크리에이터 인터뷰**와 **바이럴 미디어 콘텐츠**로 신뢰와 도달을 확보.


## 구성요소의 연결 구조

```
        인식 / 도달                         실용 / 유지
   ┌───────────────────────────┐     ┌──────────────────────────┐
   바이럴 미디어 콘텐츠(숏폼)  ──►   검색(합법 플랫폼 파인더)
   기사(SEO)                ──────►   상세페이지(위키 정보)
   크리에이터 인터뷰        ──────►   Stay Safe(불법 사이트 위험)
   마케팅 / 파트너십        ──────►   About
   └───────────────────────────┘     └──────────────────────────┘
```

미디어 콘텐츠와 마케팅이 **사람을 데려오고**, 검색 경험과 Stay Safe 콘텐츠가 **전환·유지**해 합법 경로에 머물게 합니다.
