# 07 · 마케팅 계획


마케팅은 두 블록으로 정의됩니다. **(A)** 웹사이트 자체 홍보, **(B)** 바이럴 미디어 콘텐츠 전략. 각각 별도의 타깃·가치제안·채널을 가집니다. 실질 내용은 "Marketing Report"에 있고, "Marketing Plan" 문서는 현재 빈 골격 상태입니다.


## 블록 A — 웹사이트 자체


### 타깃 오디언스

| 세그먼트 | 정의 |
|----------|------|
| Webtoon Explorers | 재미있는 작품·공식 플랫폼을 찾는 팬 |
| Information Seekers | 특정 작품의 잘 정리된 정보를 찾는 사람 (특히 덕후) |
| Convenience Seeker | 한 곳에 다 모여 있어서 불법 사이트를 쓰는 사용자 |
| International Fans | 한국 밖에서 자국어 공식 번역을 찾는 팬 |
| Safety-Conscious Readers | 기기를 위협으로부터 지키려는 독자 |
| Other Huge Webtoon Fans | 그 외 열성 팬 |


### 가치 제안

- **Webtoon Discovery Hub** — 랭킹·추천으로 탐색
  - 전 산업을 아우르는 **크로스 플랫폼 랭킹** (실제 업계 트렌드 표시)
  - 단순 장르가 아닌 독창적 추천 카테고리 — 예: *"비 오는 일요일 같은 웹툰"*, *"실제로 뇌세포가 있는 주인공"*
  - **로그인 기반 개인화 추천** + 사용자 **리딩 리스트**
- **Information Compilation** — 설명·장르·평점·리뷰 통합 정리
- **Comprehensive Platform Search** — 작품 제공 공식 플랫폼 목록 (비용·언어/지역·최신화 정보)
- **Dangers of Using Piracy Sites** — 보안 위협, 기기 안전 점검법
- **Behind the Scenes of Webtoon Creation** — 크리에이터 인터뷰(작가 스케줄, 스태프, 프로세스)


### 채널

| 채널 | 목표 | 장점 | 단점 |
|------|------|------|------|
| 숏폼 영상 (Reels, TikTok, YT Shorts) | 재미 콘텐츠로 바이럴 + 사이트 홍보 | Gen Z/Alpha 웹툰층 대규모 도달 | 예측 불가 알고리즘; 꾸준한 제작 필요 |
| 인터넷 커뮤니티 (DCinside, 네이버카페, Reddit, Discord) | 신뢰 구축; 커뮤니티 도구로 자리매김 | 덕후에게 직접 접근 | 자기 홍보 비선호 — 먼저 활동 멤버 되어야 |
| SEO | 가시성/브랜드 발견; 작품 검색하는 불법 이용자 **가로채기** | 고관여 트래픽 | 경쟁 키워드 |
| 협업 (크리에이터·플랫폼·인플루언서) | 신뢰·권위 구축 | 즉각적 권위·신뢰성 | 접촉/허가 받기 어려움 |
| QR 게릴라 마케팅 | 웹툰 이벤트 현장에서 열성 팬 포착 | 정확한 타깃, 대면 | 체력 소모; 물리 자재 필요 |


## 블록 B — 바이럴 미디어 콘텐츠


### 타깃 오디언스 (블록 A와 별도)

| 세그먼트 | 정의 |
|----------|------|
| Unaware Fans | 불법복제가 창작자·본인에게 끼치는 피해를 모름 |
| Budget-Constrained Fans | 공식 플랫폼 비용을 못 냄 (특히 10대) |
| Skeptic Fans | 웹툰사·작가가 이미 충분히 번다고 생각 |
| Those who just don't care | 그냥 신경 안 씀 |


### 핵심 메시지

- **The Personal Stake** — 불법 사이트가 사용자 본인에게 주는 위험
- **Creator Connection** — 크리에이터 인터뷰·작업 과정으로 공감
- **Webtoon Industry Collapse** — 품질 하락 이유; 시장 자체가 사라질 수 있음
- **Quality Gap** — 공식 vs 불법의 번역·이미지 품질 비교
- **Entertaining Topics first** — 재미 콘텐츠를 우선, 사이트는 부차적으로(끝부분·댓글) 링크


### 채널 (상세)

- **숏폼:** YouTube Shorts, TikTok, Instagram Reels
- **커뮤니티 참여:**
  - 한국: 네이버카페, DCinside, TheQoo, ArcaLive, FMKorea, Inven
  - 비한국: Reddit, Discord, Threads, X(Twitter)
- **협업:** 플랫폼 파트너십 / 크리에이터 / **안티-불법복제 단체** (예: Alliance for Creativity and Entertainment)
- **Pinterest** (비주얼 검색엔진으로 활용)
- **SEO**
- **위키** — "external links" 섹션에 작은 도움말 + 사이트 링크
- **오프라인 마케팅** — *아직 미작성*


### 재미있는 콘텐츠 주제

- 웹툰 추천
- 웹툰 제작 비하인드 (작가 스케줄, 발행 과정)
- 특정 웹툰 분석 (예: *"[작품] 100화 숨은 디테일"*)
- 쿠키 무료 획득법 (현재 이벤트, 세일 등)


## 미정 항목 (의사결정 필요)

- **KPI/지표:** 어디에도 정량 KPI 없음 — 채널별 정성 목표만.
- **예산/리소스:** 명시 예산 없음; 리소스 부담은 단점으로만 언급(QR 자재, 숏폼 지속 제작).
- **일정/콘텐츠 캘린더:** 없음 (Zoom 인터뷰 "20~30분"만 유일한 시간 정보).
- **"Marketing Plan" 문서**는 빈 골격(Value Propositions / Channels / Media Contents 헤더만) — Report 기반으로 채워야 함.
