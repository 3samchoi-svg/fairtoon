# 04 · 웹사이트 기획


**최신** "New Fairtoon Website Plan" 기준의 핵심 기획서입니다. 웹사이트는 초기 캠페인형 디자인에서 **검색엔진 우선형**으로 전환되었으며, 전환 히스토리는 문서 하단에 정리했습니다.


## 목적과 타깃 사용자

| | |
|---|---|
| 핵심 미션 | 대중 인식을 높여 불법 사이트 사용을 줄임 |
| 프레이밍 | **자기 이익 기반** ("당신/당신 기기에 해롭다"), 훈계 아님 |
| 1차 사용자 | 이미 합법으로 보고 싶은 독자 → **검색**으로 해결 |
| 2차 사용자 | 사이트를 모르는 독자 → **SEO / 기사**로 도달 |
| 제약 | 마케팅 예산 없음 → 오리지널 콘텐츠 + SEO가 성장 엔진 |


## 사이트맵

**헤더 (전 페이지 공통):** 로고(미정) · Home · Articles · Stay Safe · About · 검색바 · 언어 선택

**언어:** 한국어, 영어 (2개)

| 페이지 | 기능 |
|--------|------|
| Home | 중앙 대형 검색바 |
| 초기 검색 결과 | 일치하는 웹툰 시리즈의 카드 뷰 |
| 특정 검색 결과 | 클릭한 시리즈의 상세 페이지 |
| Articles | SEO + 안티-불법복제 심층 콘텐츠 (아래 참고) |
| Stay Safe | 불법 사이트가 왜 위험한지, 자기 이익 관점으로 |
| About | "기타" (아직 미상세) |
| Explore | **당분간 미개발** (보류) |

> 원본 기획서는 "Website Structure" 탭이 미완성임을 명시 — 그대로 구현하지 말고 잘 맞는 섹션을 추가할 것.


## 4대 핵심 기능

1. **Search** — 메인 기능
2. **Explore** — 보조 / 추후 (또는 미개발 가능)
3. **Articles**
4. **Stay Safe**


### 기능 1 — Search (메인)

특정 작품을 검색하면 위키처럼 유용한 정보를 얻되, 가장 중요하게 **어떤 합법/공식 플랫폼**이 해당 작품을 제공하는지 비교(접근 모델, 언어 제공 등)를 보여줍니다. 목표는 합법 이용을 편리하게 만들어 불법복제의 이점을 없애는 것. 시놉시스·장르·평점 같은 위키성 부가정보로 단순 플랫폼 검색보다 매력적으로 만듭니다.

**DB 규모:** 150~300편 (변동 가능). 품질을 위해 의도적으로 범위 제한 — *"정확·최신 150편이 불완전 1000편보다 낫다."* 인기도 + 데이터 확보 용이성으로 우선순위.

**카드 뷰 (검색 결과)** — 제목(최근접 1개) · 표지 이미지 · 작가(작화 제외) · 주요 장르 태그 2~3개 · 단일 커뮤니티 평점 · 제공 합법 플랫폼(이름+로고만).

**상세 페이지 — 6개 블록:**

1. **핵심 정보** — 제목(원제 한국어 + 모든 대체 제목), 표지, 작가·작화, 퍼블리셔, 연재 기간, 상태(연재중/완결/휴재/취소), 연재 스케줄, 총/현재 화수
2. **합법 플랫폼** — 플랫폼명+로고, 지역 가용성, 언어 가용성, 가격 모델, 최신 화수(원어+번역) 및 최근 업데이트일, 작품 직접 링크, 웹/앱/둘다
3. **장르·콘텐츠 정보** — 주요 장르 태그, 카테고리 태그(예: 던전, 레벨 시스템), 콘텐츠 경고, 연령 등급, 줄거리(스포일러 최소)
4. **평점·반응** — AniList / MangaUpdates 점수·랭킹, 긍정/부정 노트, 수상
5. **각색·관련 미디어** — 관련 시리즈, 애니/드라마, 라이트노벨, 단행본 + 접근 경로
6. **유사 작품** — 약 5개 추천, 각 1줄 추천 사유


### 기능 2 — Articles

두 가지 목표: **(a)** 오가닉 검색 트래픽 유입(SEO); **(b)** 단순 검색 도구를 넘어 안티-불법복제 자원으로서 신뢰도 심화.

| 등급 | 카테고리 |
|------|---------|
| **Tier 1 (주력)** | 이슈 심층(불법복제 원인·창작자 경제·운영 방식) · 데이터&시각화(오리지널 차트 분석: 가격 비교, 번역 지연 추적, 불법 트래픽) · 크리에이터 관점(공개 발언 종합, 신뢰 확보 후 인터뷰) · Stay Safe 확장(롱폼) |
| **Tier 2 (소량 추가)** | 일반 플랫폼 비교 · 불법 사이트의 수익 구조 · 독자 행동·심리 |

**운영:** 발행 시 5개 이상 확보 → 이후 월 2회 발행. 사이트 전역 → 기사 내부 링크, 기사 ↔ 검색 결과 상호 링크(독자 ↔ 검색 사용자 전환).


### 기능 3 — Stay Safe

불법 사이트의 위험을 독자에게 설명해 사용을 만류. 자기 이익 프레이밍, 가시성을 위해 Articles와 **별도 섹션**으로 유지.

- **흔한 위협** — 멀버타이징, 가짜 "플레이어 업데이트" 프롬프트, 알림 권한 남용 등
- **기기 안전 체크리스트** — 수동 자가 점검
- **이미 노출됐다면** — 단계별 복구(확장 프로그램 제거, 알림 권한 해제 등)

기기 유형별(아이폰, 맥북, 갤럭시 등) 차별화 필요.


## 디자인 / UX 방향

- **로고:** 최신본 미정 (구버전은 flaticon book 아이콘 `10433049` 사용).
- **룩&필 레퍼런스:** Gemini 공유 링크 `https://gemini.google.com/share/4bfece0272be` (→ [09 · 리소스](./09_리소스_링크.md)).
- **UX 규약 (구버전 기준, 여전히 유효):**
  - 밑줄 친 불릿 ⇒ 세로 순서 강제 (A, B, C 세로 배치, 가로 금지)
  - 파란색 강조 ⇒ **실제** 데이터여야 함 · 빨간색 강조 ⇒ **지어낼** 항목(플레이스홀더)
  - 미정 항목은 프로토타입에서 비워둘 것 — 빈 필러 페이지는 만들지 말 것
- **참고 도구:** Figma; 외부 데이터 — TV(JustWatch, IMDb), 만화/웹툰(AniList, Anime-Planet, MangaUpdates, MyAnimeList, Kenmei)
- **기술 스택:** 기획 문서에 명시 없음. (실제 프리뷰는 단일 파일 `index.html` — 저장소 상태이며 원본 명세는 아님.)


## 버전 히스토리 — 전환

초기 "Fairtoon Website Workflow"는 **다른 컨셉**, 즉 캠페인/액티비즘 사이트였습니다. 현재 기획은 의도적으로 **위키형 합법 플랫폼 검색엔진 + SEO 기사 + Stay Safe**로 피벗했습니다.

| | 구버전 (캠페인형) | 현재 (검색 우선) |
|---|------------------|------------------|
| 네비게이션 | Creator Voices / Risks of Piracy / Data Lab / How to Help / About Us | Home / Articles / Stay Safe / About |
| 검색 | 헤더 내 보조 "Where to Read?" 도구 | **메인 기능** |
| 언어 | EN / KO / **JP** (3개) | EN / KO (2개) — 일본어 제거 |
| Home | 히어로 + 창작자 인용 + 인터랙티브 데이터 + 전자서명 | 단일 대형 검색바 |

**보류/폐기됐으나 재도입 여지가 있는 기능** (구버전): Creator Voices(창작자 카드 + 인터뷰), Data Lab(데이터 시각화 전용 섹션), How to Help CTA, **전자서명**(불법복제 미사용 서약), **Report a Pirate**(불법 사이트 신고), **인터랙티브 수익손실 계산기**(슬라이더 → 추정 수익 손실). 모두 의도된 캠페인 기능으로, 추후 재도입 후보로 보존.
