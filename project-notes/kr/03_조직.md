# 03 · 조직 구조


조직은 중앙집중형입니다. **CEO가 데이터·제품기획·미디어를 직접 관장**하고, 3개 부서가 개발·콘텐츠·마케팅을 담당합니다. 원본 문서는 역할을 **부서 단위**로 정의하며, 개인 실명은 기재되어 있지 않습니다.


## CEO — 직접 담당

- **전반 리더십 및 의사결정**
- **데이터 축적**
  - 불법복제 피해 raw data 리서치·수집 (개인 수익 손실, 산업 쇠퇴 등)
  - 데이터 출처 기록
  - 수집 데이터를 그래프/차트로 분석
  - 분석 데이터를 개발 부서에 전달
- **웹사이트 제품 관리**
  - 초기 프로토타입(웹사이트 워크플로 + 비주얼 디자인) 설계 후 개발 부서에 전달
  - 첫 프로토타입 이후, 그리고 매 정제 시점마다 피드백(주요 항목 중심: 전반 디자인, 추가 기능)
- **미디어 콘텐츠 관리**
  - 콘텐츠 부서 기획 기반 크리에이터 인터뷰 진행 (컨택 + 인터뷰)
  - 콘텐츠 부서 기획·프로토타입에 피드백
- **기타** — 웹사이트 번역 (한국어, 영어, 일본어)


## 개발 부서 (Development)

- **프로토타입 개발 (출시 전)** — 데이터·워크플로·비주얼 디자인 기반 첫 프로토타입 제작, 피드백 기반 정제
- **웹사이트 출시** — 완성된 프로토타입 게시
- **웹사이트 정제 (출시 후)** — 피드백 기반 정제, 오류 수정, 디자인/비주얼 개선
- **웹사이트 분석·추적** — 핵심 지표 추적 (사용자 수, 페이지 체류 시간 등)


## 콘텐츠 제작 부서 (Contents Production)

- **미디어 콘텐츠 제작** (인터뷰 포함)
  - **1차 목표:** 이슈·웹툰 산업에 대한 정보성/엔터테인먼트성 콘텐츠로 인식 제고 (숏폼 영상, SNS 게시물 등)
  - **2차 목표:** 콘텐츠에 삽입한 링크로 사이트 유입 증대
- 1차 초안(프로토타입) 콘텐츠 제작, 피드백 기반 정제, 업로드


## 마케팅 부서 (Marketing)

- **소셜 미디어 게시물 제작** — 여러 플랫폼에서 웹사이트 자체를 광고. 이는 **순수 홍보용**으로, 콘텐츠 부서의 미디어 콘텐츠와 구분됨.
- **파트너십 구축**
  - 웹툰 플랫폼·기타 조직과 — 홍보 및 추가 활용
  - 학교와 — 학생 대상 사이트 홍보


## 두 종류의 콘텐츠 — 핵심 구분

| | 제작 주체 | 목적 |
|---|-----------|------|
| **미디어 콘텐츠** | 콘텐츠 제작 부서 | 인식 제고(1차) + 사이트 유입(2차) |
| **소셜 미디어 게시물** | 마케팅 부서 | 사이트 홍보 전용 |


## 의사결정 흐름

CEO 중심 중앙집중형, 모든 부서 산출물을 CEO가 승인:

```
            ┌──────────── CEO ────────────┐
            │ (데이터 · 제품 · 미디어 · 승인)
            ▼            ▼            ▼
          개발          콘텐츠        마케팅
        (구축)       (인식제고)   (홍보 + 파트너십)
            ▲            │
            └── 데이터 ──┘   인터뷰 기획 → CEO가 인터뷰 실행
```


> 참고: 본 문서는 부서별 역할만 정리합니다. 멤버 명단·GitHub·인프라는 프로젝트 메모리(`fairtoon-members.md`)에서 별도 관리합니다.
