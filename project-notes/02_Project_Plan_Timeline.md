# 02 · Project Plan & Timeline


The original roadmap (drafted early 2025) runs from foundational planning through launch, then enters a repeating growth cycle.


## Timeline (2025)

| Phase | Dates | Goal |
|-------|-------|------|
| Project lean canvas & pitch deck | Jan 13 – Feb 2 | Foundational project plan + pitch deck to outline the project |
| Website prototype design | Feb 2 – Feb 16 | Prototype design for the developer to implement — outline, features, displays |
| Initial data collection | Feb 16 – Mar 9 | Collect key data on piracy damage; analyze with graphs/charts (not final — for the prototype) |
| Website prototype development | Mar 9 – Mar 30 | Build the actual prototype from the design + initial data |
| Further data collection & analysis | Mar 9 – Mar 30 | Gather more data while the site is being built, for later refinement |
| Refine website | Mar 30 – Apr 13 | Refine based on new data; fix prototype errors |
| Viral content planning | Mar 30 – Apr 13 | Plan viral marketing to promote the site and grow awareness |
| Testing & feedback on website | Apr 13 – Apr 20 | Test the refined site and give the developer feedback |
| Interview with webtoon creators | Apr 13 – May 4 | Reach out to and interview creators; recordings used for viral content and on the site |
| Finalize website and publish | May 4 – May 18 | Finalize from feedback; add creator interviews |


## Repeat cycle (post-launch)

After launch the project loops continuously:

1. Promote & advertise the website
2. Create viral content
3. Further data collection & analysis
4. Refine the website


## Where the project stands now (PM note, 2026-06)

The 2025 timeline above is the **original** plan. As of mid-2026 the project has moved well beyond it:

- The website concept was **redesigned** (see [04 · Website Plan](./04_Website_Plan.md) — pivot from a campaign site to a search-engine-first site).
- A working **website preview** exists (single-file `index.html` in the repo root, deployed to GitHub Pages) built on the latest plan.
- Data collection is **in progress**: the Search DB currently holds ~10 sample series against a 150–300 target.

This document preserves the original roadmap; current execution status is tracked in `docs/plan.md` and `docs/progress.md`.
