# 03 · 마스터 타임라인 (2026 7~12월)


> **2026-06-27 전략 피벗 반영본 (v2).** 인식 핵심 승격 + 합법 어그리게이터(딥링크, 레벨 2a) + 단속 전제 정정 반영. 6개월, 4단계. **웹페이지 제작은 7월로 전진 배치하고, 전체 프로젝트는 12월에 마감.**

## 1단계 — 7월: 제작 (웹페이지 제작 완료)

**목표:** 7/31까지 출시 가능한 프로덕션 사이트 완성.

- **웹페이지 제작** — 현재 프리뷰를 기능 완비 프로덕션 사이트로: ①디스커버리(발견·추천) ②**합법 사이트 어그리게이터** — 작품 상세에서 "보러가기: [네이버][카카오]…" 버튼이 **그 작품 페이지로 직행하는 딥링크**(없으면 검색 URL fallback) ③인식 콘텐츠(개인 위험 + 창작자 피해) ④검색·상세·Articles·Stay Safe, 한/영 i18n, 반응형·접근성. 가격은 라이트 태그(무료/기다무/유료 + 최종 확인일).
- **데이터 기반** — 1차 80편: 네이버 웹툰·카카오페이지·리디·네이버 시리즈 각 상위 20편. 작품별 **합법 플랫폼 딥링크 URL**, 무료 공개 회차 범위, 진행 이벤트, 라이트 가격 태그. (딥링크는 '데이터 한 칸 추가'이므로 수집 작업에 흡수.)
- **마일스톤 (7/31):** 웹 제작 완료 + 80편(딥링크 포함) 로드 → 출시 준비 완료.


## 2단계 — 8월: 검증·출시

**목표:** 실제 사용자로 품질을 검증한 뒤 정식 공개.

- **데이터 확장** — DB를 약 160편까지; 신규 작품·딥링크·가용성 변동 지속 업데이트.
- **베타 테스트** — 15~20명(친구·지인·학교 동아리). 디스커버리·어그리게이터로 검색→합법 사이트 이동까지 흐름 테스트, 짧은 구글폼으로 정확도·편의성 평가. 오류(딥링크 깨짐, 가용성 누락, 검색 버그) 기록.
- **수정·정제** — 우선순위 피드백부터; P1/P2 버그 전부 해결.
- **정식 출시** — 출시; 출시 콘텐츠(SNS 카드뉴스, 인포그래픽, 안내 게시물) 제작.
- **마일스톤 (8월 말):** 정식 출시; 가용성·딥링크 정확도 ≥95%; 작품당 딥링크 보유율 ≥90%; 베타 만족도 ≥4.0.


## 3단계 — 9~10월: 성장

**목표:** 출시를 사용자·인지도로 전환(오가닉 한정) + 인식 메시지 확산 + 창작자 관계 조기 착수.

- **이벤트** (4개):
  - 숨은 명작·내 최애 합법 디스커버리 챌린지 — 합법으로 본 추천작을 SNS 인증
  - 불법 웹툰 위험·피해 인지도 퀴즈 이벤트 (개인 위험 + 창작자 피해)
  - 합법 웹툰 이용 인증/서약 이벤트 (결제·구독 인증샷 + 서약)
  - 창작자 응원 메시지 캠페인 (추후 인터뷰 시 전달)
- **마케팅 채널 (인식 콘텐츠 중심):**
  - 인스타그램 — 위험·피해 통계 카드뉴스, 디스커버리·사용법, 이벤트 홍보
  - 유튜브 / 틱톡 — 불법 사이트 위험성(악성코드·사기·계정탈취) 쇼츠, 기능 데모, 추천 큐레이션
  - 블로그 / 네이버 카페 — "왜 합법으로 봐야 하나" + "합법으로 잘 찾아보는 법" SEO 글
  - 커뮤니티(에브리타임, 웹툰 갤러리) — 이벤트 + 정보성 게시글
  - 협업 — 저작권 단체, 작가 협회, 웹툰 인플루언서
- **인식 콘텐츠** — 8개+ 발행; 검색·상세로 내부 링크.
- **창작자 관계 조기 착수** — 국내 작가 접근성을 활용해 4단계 인터뷰 전 협회·작가 컨택 시작.
- **마일스톤 (10/31):** 누적 방문 3,000명, SNS 1,000명, 딥링크 아웃바운드 클릭 500회, 이벤트 4개, 창작자 컨택 5곳+.


## 4단계 — 11~12월: 미션·마감

**목표:** 인식 변화를 측정·이행하고 연말 마감.

- **태도 변화 측정** — 사전/사후 설문으로 합법 이용 의향 변화 확인(측정 정직성 원칙).
- **수익구조 / MG 분석** — 플랫폼별 창작자 정산 비율·수익 배분·MG 제도 조사; 합법 이용이 창작자 수익에 미치는 영향 분석; 비교 보고서 발행.
- **국내 창작자 인터뷰 (영상 + 숏츠)** — 저작권/불법유통에 목소리 내는 국내 창작자 우선 선별; 협회·저작권·권익 단체 메일; 5건 인터뷰(서면 또는 20~30분 Zoom). **인터뷰 영상은 Fairtoon '작가의 목소리' 코너에 게재**하고, **핵심 발언을 숏츠로 편집해 유튜브·틱톡·릴스에 업로드**(인식 확산 + 유입 동시). 핵심 발언 + 피해 사례 정리.
- **연말 마무리** — 프로젝트 완료 보고서; 최종 KPI 정산.
- **마일스톤 (12/31):** 인터뷰 5건 게시, MG 보고서 발행, 태도변화 설문 완료, 프로젝트 완료.


## 크리티컬 패스 & 의존관계

- **웹 제작(7월)이 모든 것의 관문** — 베타·출시·전 마케팅이 동작 사이트에 의존. 7/31 사수; 위험 시 범위 축소(디스커버리·어그리게이터·인식 핵심이 아니라 Articles 심도를 후순위).
- **데이터·딥링크 정확도가 출시의 관문** — 깨진 딥링크로 출시 금지; 합법 라우팅의 신뢰가 제품 핵심. (실시간 아님 = '최종 확인일' 명시로 기대치 관리.)
- **출시·트래픽(8~10월)이 인터뷰(11~12월)의 관문** — 청중이 생긴 뒤 창작자 응답률↑. 단 국내 작가 접근성 높아 컨택은 3단계 조기 착수.
- **창작자(1인) 가용 시간이 최대 제약** — 1인(고등학생)·무예산 → 순차(제작→출시→성장→미션) 설계. 단계 중첩 금지.
