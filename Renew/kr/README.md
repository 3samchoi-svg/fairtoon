# FairToon — 리뉴 프로젝트 계획 (2026 하반기)


프로젝트의 **목표·KPI·타임라인**을 하나로 통합한 새 마스터 계획입니다. 2026-06-25 작성.

**대표님이 설정한 두 앵커:**
- **웹페이지 제작은 2026년 7월 내 완료.**
- **전체 프로젝트는 2026년 12월 내 완료.**


## 작성 배경

기존 기획 자료는 [`../project-notes/`](../project-notes/)에 그대로 보존돼 있습니다 — 지호님 초기 계획과 유스임팩트 컨설팅 타임라인 간의 실제 의견 차이(데이터 목표 규모, 플랫폼 목록 등)도 그대로 둡니다. 본 Renew 세트는 그것을 **덮어쓰지 않으며**, 그 차이를 하나의 실행 가능한 2026 하반기 로드맵으로 정합화한 **향후 마스터 계획**입니다.

영문본은 상위 폴더([`../`](../))에 있습니다.

## 전략 피벗 — 2026-06-27 대표님 확정 (결정 5건)

[`00_전략_재평가`](./00_전략_재평가.md) 권고 + 단속 효과 팩트체크를 거쳐 대표님이 결정한 5건을 01·02·03에 반영했습니다.

1. **가격비교 강등** — 핵심에서 내려 라이트 보조 태그(무료/기다무/유료 + 최종 확인일)로만.
2. **미션 재정의** — "(측정 불가) 불법 사용 감소" → **"불법 이용 인식·태도 변화 + 합법 이용 전환"**.
3. **한국 우선(v1) → 국제 확장(v2) 단계화** — 학생 비교과·포트폴리오 + 지역 기여 목적상 실행 신뢰성·진정성 우선.
4. **인식 제고를 핵심 축으로 승격** — 합법은 '무료'를 못 이기므로, 사람을 옮기는 유일한 지렛대는 인식·태도 변화. 인식(동기) + 유틸리티(마찰 제거)를 **깔때기**로 결합.
5. **합법 사이트 어그리게이터(딥링크, 레벨 2a) 추가** — 작품별로 합법 플랫폼의 그 작품 페이지로 직행. 추상적 인식 페이지를 넘어 합법 이용을 한 클릭으로. (실시간 추적=레벨 3은 범위 밖.)

> **단속 전제 정정:** 직전 버전의 "한국은 단속 효과로 문제 축소"는 사실과 다름 — 2026년 긴급차단에도 뉴토끼 하루 만에 부활·사이트 증가(두더지잡기). 공급은 못 죽이므로 **수요·인식이 유일한 지속가능 지렛대**라는 논리로 교체. 이 사실이 인식 중심 + 한국 우선을 더 정당화함.


## 정합화 판단 (클상무)

1. **타임라인 압축** — 유스임팩트의 약 8개월 계획을 6개월(7~12월)로 압축하고, 웹페이지 제작을 7월로 전진 배치.
2. **데이터 목표 정합화** — 유스임팩트의 단계형(80→160편)을 근시일 운영 목표로, 웹사이트 기획의 150~300편은 연말 스트레치로 통일.
3. **KPI 수치 신설** — 원본 문서에 KPI가 전무했음. [02 · KPI](./02_KPI.md)의 수치는 무예산·1인 프로젝트에 맞춘 초안이며 8월 출시 후 재기준화 필요.
